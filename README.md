# 🌍 AI Study Abroad Advisor

An intelligent study-abroad recommendation system that analyzes a student's academic profile, English proficiency, desired field, degree and budget to identify suitable study programs.

## 🚀 Current Features

- Student profile input
- CGPA validation
- IELTS score validation
- Budget validation
- Degree normalization
- Field normalization
- Country filtering
- Program/university search
- Program eligibility checking
- Matched criteria
- Reasons for rejection
- Profile match score
- Profile match level
- Improvement suggestions
- Eligibility summary
- Most affordable eligible program
- Program comparison
- Recommended programs
- Streamlit web interface

## 🛠️ Tech Stack

- Python
- Streamlit
- Git
- GitHub
